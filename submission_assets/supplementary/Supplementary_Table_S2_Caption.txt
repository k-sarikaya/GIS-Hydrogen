Supplementary Table S2. Techno-economic parameter set for Stage III, with sources and evidence levels. The CSV gives, for each parameter, the triangular fuzzy low/mode/high values, the unit, the price basis year and currency, the full source reference, and an evidence level recording how far each source was read: FT = full text or full relevant section, FT-sec = full text of a secondary compilation, Ex = excerpt or search highlight, Abs = abstract only. Values marked (D) were derived by the author. Derivations for all values marked (D), the deterministic Tuz Golu facility data used in the model, and additional model inputs are documented in the Notes to Table S2 section; the underlying source notes are also available in the project GitHub repository.
